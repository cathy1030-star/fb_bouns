# 得獎資料統計系統

這是一個簡單的網頁工具，用於輸入並統計活動得獎名單。

## 功能
- 單筆輸入得獎資料。
- 批量貼上名單（支援從 Excel 複製貼上）。
- 自動統計重複出現的次數。

## 如何執行
1. 確保電腦已安裝 [Go](https://go.dev/).
2. 在終端機執行：
   ```bash
   go run main.go
   ```
3. 開啟瀏覽器訪問：`http://localhost:8080`

## 檔案結構
- `main.go`: Go 後端伺服器。
- `index.html`: 前端網頁介面。
- `go.mod`: 專案模組設定。
