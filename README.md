# 🏆 中獎管理系統

這是一個專為活動名單整理設計的輕量化統計工具。

## 🚀 功能特點
- **紀錄備註**：輸入姓名、AccID、日期與金額，並可自動根據備份名單帶出 ID。
- **中獎名單備份**：存放基礎名單，支援批量從 Excel 匯入（Tab 分隔）。
- **總計統計**：自動加總備註與備份名單中的中獎次數。
- **批量排名**：輸入名單後自動根據歷史統計進行排名。
- **本地儲存**：資料儲存在瀏覽器中，不需伺服器，安全且隱私。

## 📂 檔案結構
- `index.html`: 主程式檔案，包含所有邏輯與樣式。

## 🛠 如何在 GitHub Pages 使用
1. 將此專案上傳至 GitHub 儲存庫。
2. 進入儲存庫的 **Settings** > **Pages**。
3. 在 **Branch** 選擇 `main` 並點擊 **Save**。
4. 幾分鐘後，您的網頁將會透過 `https://<您的帳號>.github.io/<儲存庫名稱>/` 公開存取。

## 💡 注意事項
- 本系統使用瀏覽器的 `localStorage` 儲存資料。
- 如果清除瀏覽器快取或更換瀏覽器，資料將會消失。建議定期備份您的重要資料。
